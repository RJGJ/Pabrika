# Security audit checklist (Phase 6)

Source: `specs/phase-6-ship.md`, Task 4. Status is `pass`, `fail` or `exception: <reason>`, followed by the evidence. `make audit` (`sh scripts/audit.sh`) runs the grep, tool, vet, test and dependency checks in one go and exits non-zero on a failure. Everything below was verified against the real code on Windows without Docker; what needs Docker, a proxy or the sqlite3 CLI is marked NOT RUN. The tests added for this audit are in `internal/httpapi/audit_test.go` and `internal/mcpserver/audit_test.go`.

Header values must equal Phase 2 section 11 character for character. Where a check is a test, "reuse" means the owning phase's test may be named as evidence.
